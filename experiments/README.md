# Experiment evidence

Existing baseline results are in `logs/`; current baseline docs are in `docs/baseline/`.

Future defense runs belong under pdirect/, pintent/, or lightweight/ with a unique dated subdirectory. Record code revision, exact commands, copied input dataset or version/hash, model digest/settings, machine, outputs, errors, completion details, timing, review labels, and observations. Never overwrite a preserved run. Use consistent schemas when integrating comparisons.
